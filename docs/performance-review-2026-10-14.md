## 평가 기준이 요구하는 변화

[공식 진행·평가](https://nova.snubhai.org/evaluation/)는 실제 상호작용 로그와 기록을 함께 평가합니다. 묻지 않은 사실을 기록에 덧붙이는 것은 정보수집이 아닙니다. 혈액·영상 검사는 예선에서 시행할 수 없으며 향후 계획으로만 기록해야 합니다. 샘플 검증은 gpt-6-luna 기반 참고 점수이고 공식/최종 평가와 다릅니다. 증례별 상세 기준과 채점 프롬프트는 비공개이므로 100점을 보장할 수 없습니다.

현재 부족 점수의 대부분은 정보수집과 의사소통입니다. 진단 정확도만 높이거나 프롬프트에 채점 항목을 길게 넣는 대신, 빠지는 행동이 실제 수행되도록 해야 합니다. E1의 효율은 거의 만점이라 이를 위해 불필요한 반복·모델 호출을 늘리지 않는 것이 중요합니다.

## 코드에서 확인한 병목

1. LLM이 KB 추천을 무시하거나 필수 병력·진찰 전에 DONE을 선택해도 종료됩니다. 추천 목록이 있다는 것과 실제 수행은 다릅니다.
2. 직접 작성한 질문은 목표 슬롯 ID가 없어, 짧은 답변만으로 어떤 항목을 확인했는지 추적되지 않는 경우가 있습니다.
3. 약물 종류·복용량·기간, 생활 영향 등 일부 중요한 내용은 기존 표현 사전만으로 충분히 수집·보존되지 않습니다.
4. `write_record()`가 생성된 P 전체를 KB의 일반 계획으로 덮어써 개인별 추적 시점·검사 이유가 사라집니다. 일반 계획은 누락 보완용이어야 합니다.
5. E1 마무리는 진단·계획·걱정 응답에 집중하고, 구체적인 추적·위험 증상 설명과 teach-back을 항상 수행하지 않습니다.
6. 30자를 넘는 자유 행동은 문자열을 잘라 문장이 불완전해질 수 있습니다.

## E2 구현

`hybrid_care`는 E1을 보존한 별도 후보입니다. 실제 주호소, 연령·성별과 관찰된 약물 사용에 따라 필수 병력·진찰을 선택합니다. 샘플 ID·이름·정답·대본을 읽거나 고정 진단으로 분기하지 않습니다.

- 기본 병력·약물·알레르기·생활 영향과 기존 주호소별 문진·진찰의 누락을 확인합니다.
- 필요한 고정 질문은 모델에게 매번 선택시키지 않고 수행해 선택 비용을 줄입니다. 추가 감별은 LLM이 수행합니다.
- 복합 질문 대신 부모 키 등을 나누어 묻고, 추가 문진은 질문·원문 응답·턴과 함께 보존합니다. 모른다는 답을 확인된 음성으로 바꾸지 않습니다.
- 수면제 사용이 실제 확인된 경우에만 상세 복용력을 추가합니다. 어린 아동의 성장 평가에 사춘기 진찰을 일괄 적용하지 않습니다. 가임기 체중 감소 상담의 임신·수유 조건을 확인합니다.
- E2에서만 개별 P와 감별 근거를 보존하며 기본 E1의 기록 동작은 유지합니다.
- 진단·계획·추적·위험 증상·걱정 응답을 분리해 설명하고, 이해를 되묻습니다. 길이 초과 행동은 자르지 않고 거부합니다.
- 문진·진찰 최대 36턴과 마무리 여유를 두며 전체 상호작용은 서버의 50턴 한도를 지킵니다. 시간 부족 시 기록 제출을 우선합니다.

다만 필수 목록의 양과 추가 설명은 실제 행동 수를 늘릴 수 있습니다. 총점 개선 여부는 새로운 서버 샘플 검증으로 확인해야 합니다. 아직 E2의 100점 또는 점수 상승을 측정했다고 주장하지 않습니다.

## 임상 설계 출처와 한계

- [VA/DoD 2025 수면 지침](https://www.healthquality.va.gov/guidelines/CD/insomnia/): 수면·의학·정신건강 병력과 약물/물질 평가. 새 질문은 팀 작성 초안이며 임상 검수 전입니다.
- [FDA benzodiazepine 안전 안내](https://www.fda.gov/drugs/drug-safety-and-availability/fda-requiring-boxed-warning-updated-improve-safe-use-benzodiazepine-drug-class): 급격한 중단·감량의 금단 위험. 에이전트에 임의 증량/갑작스러운 중단을 권하지 않도록 지시합니다. 개별 약물의 치료 결정을 자동 확정하지 않습니다.
- [Pediatric Endocrine Society 성장 평가](https://pedsendo.org/clinical-resource/child-with-suspected-short-stature/): 연속 성장 기록, 출생·가족·전신 병력과 연령 맥락.
- [NIDDK Graves' disease](https://www.niddk.nih.gov/health-information/endocrine-diseases/graves-disease): 병력·진찰 후 확인 검사, 임신·수유와 검사/치료 선택의 관계.

원문 또는 채점용 샘플 답안을 제출물에 추가하지 않습니다. 질문은 진료 가설과 정보 확인을 위한 것이며 병명 확정 규칙이 아닙니다.

## 실제 개발 API 시험 기록

- 최초 불면 시험: HTTP의 비JSON 응답이 반복돼 제출 실패. 같은 세션/요청 ID로 최종 제출을 복구했습니다. 이 실행을 점수 개선 근거로 사용하지 않습니다.
- 재시도 구분을 넣은 중간 불면 시험: 502·503·처리 중 응답 때문에 필수 수집 전에 마무리해 8턴으로 제출됐습니다. 점수 없음. 성공적인 정보수집 검증으로 간주하지 않습니다.
- 성장 시험: 35턴, 약 201.6초, Doctor 11호출/15,484토큰으로 제출 완료. HTTP 502 1건은 같은 요청 ID 재시도로 복구했습니다. API 시도 수와 성공한 턴 수를 구분합니다.
- 성장 시험에서 일반 만성질환 질문 반복과 LLM의 어린 아동 사춘기 검사 선택을 발견해 후속 후보에서 차단했습니다. 마지막 ZIP은 이 추가 보완의 오프라인 회귀 검증까지 반영합니다. 35턴 실행과 마지막 ZIP을 완전히 동일한 코드의 시험으로 주장하지 않습니다.

이 개발 세션의 서버 응답은 모두 `not_scored`입니다. 원시 로그는 `.run/care-validation/`에만 보존하며 ZIP에 포함하지 않습니다. 결과의 정상 접수와 품질/점수 상승은 구분합니다. 아직 최종 E2 샘플 검증 점수는 없습니다.

### 재현 명령

```powershell
python -X utf8 -m unittest discover -s tests -q
python -X utf8 tools/make_submission.py --starter data/external/starter/run.py --agent hybrid_care --knowledge-mode clinical --out dist/submission_E2_hybrid_care.zip
```

E1의 기본 clinical 설정을 비교 기준으로 합니다. 임상 커버리지 변화와 온톨로지 효과를 한 번에 섞지 않기 위해 E2도 clinical로 먼저 검증합니다. 통합/온톨로지 효과는 같은 E2 위에서 별도로 비교할 수 있습니다.
