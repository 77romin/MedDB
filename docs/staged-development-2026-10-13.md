# 단계별 개발 기록

1. 공개 증례 3건의 19항목 점검표 작성. 구조화된 문진·감별·계획 요구사항 12개 누락 확인. 그래프 끝 열은 관찰 가능한 소견으로 명확히 표시. 커밋 e4c91a9.
2. 독립 지침 기반 요구사항 12개 보강, 모두 초안 유지. 사춘기 평가 맥락을 명시하면 연령에 적절하지 않은 사춘기 지연 소견의 점수·추천을 제외. 커밋 c115f4e.
3. 사건 출처를 요구하는 조회 규약, HTTP/도구 인터페이스, 연결 예제, 번들 검증. 커밋 d766fd4.
4. 이전/개선 코드를 각각 커밋으로 고정해 같은 공개 참고 사실로 9회 KB 비교. 모델 호출 0회. 실제 에이전트 비교 계획과 실행 도구 작성. 사용자의 요청에 따라 실제 진료 평가를 실행하지 않음.

관련 문서: public-case-checklists.md, clinical-pathways.md, agent-contract.md, agent-ablation.md.

모든 추가 지식은 검수 전이며 임상 검수 완료나 진단 정확도 개선을 뜻하지 않는다. 공개 증례의 대본·모범 기록은 평가 경로에만 있고 전달용 지식 번들에는 없다. 작은 공개 자료에 맞춘 결과를 비공개 대회 성능으로 일반화하지 않는다.
