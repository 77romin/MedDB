# MedDB 현재 상태와 남은 작업

참고 사이트와 유사한 촘촘한 목록·방향 그래프·관계 테이블 탐색을 구현했다. DisMech 3,333개 항목과 기존 파일럿을 연결해 질병 3,339개, 소견 5,612개, 기전 23,631개, 관계 114,088개를 탐색한다. HPO 표준 소견과 출처의 MONDO 매핑을 보존한다.

완료: 버전 고정·원본 SHA256·관계별 출처와 문헌 참조, 방향 탐색, 소견 입력, 공통점 후보, 표준 코드 검색, 초안 구분, 구조 및 페이지별 테이블, 한국어 일부 초안 번역과 영어 원문 표시, 테마와 모바일 목록, importer 릴리스 덮어쓰기 거부, 압축 전송.

검증: 전체 JSON 구조 검증, 초기 작은 판의 전체 RDF/SHACL, 최신 윌슨병 2단계 결과 방향의 2,424 triple RDF/SHACL, 테스트 22개 및 브라우저 주요 흐름. 의료적 타당성·표준 매핑 의미·기사 참조는 독립 임상 검수 전이다.

남은 작업: KCD 및 LOINC 검사 데이터 연결, PostgreSQL 저장과 검수 이력, 한국어 용어 검수 및 번역 확대, 대규모 RDF 전체 검증 작업, 환자 맥락을 고려한 후보 필터, 전문가의 임상 증례 평가. 참고 사이트의 자체 수집 자료는 포함하지 않았다.
