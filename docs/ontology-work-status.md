새 의료 판 `meddb-2026.10.13.1`을 기본으로 선택한다. 기존 데이터 판은 변경하지 않았다. 새 질환 2개, 새 소견 1개, 새 초안 관계 4개이며 전체 관계는 114,092개다. 모두 검수 전이다.

사용장애 관계는 [SAMHSA 공식 보고서](https://www.ncbi.nlm.nih.gov/books/NBK519702/)의 갈망 설명에 근거한다. 체질성 성장지연 관계는 [독립 CDGP 문헌](https://pmc.ncbi.nlm.nih.gov/articles/PMC8944060/)을 근거로 한다. 단일 소견을 확정 진단으로 해석하지 않으며 신체 의존과 사용장애를 동일시하지 않는다. 성장·사춘기 연관만으로 다른 원인을 배제하지 않는다. 확정된 연령·성별 필터는 추가하지 않았다.

공식 사이트에서 받은 15,904개 지침 원본은 변경 없이 로컬에 보존했다. 참고 문서층과 질환 제목 연결은 의료 주장과 구분한다. 문서별 라이선스가 붙은 원문 일부를 런타임에서 조회하며 원문·증례 정답은 실행 번들에 포함하지 않는다.

## 사용

```powershell
python -m meddb serve
```

진료 화면에서 환자 표현을 해석하고 소견/상태를 확인한 뒤 적용한다. 초안 사용 범위를 선택해 후보와 다음 행동 근거를 조회한다. 공식 진료지침 검색도 같은 화면에서 사용할 수 있다.

팀의 에이전트에는 `dist/nova-knowledge-bundle.zip`을 연결한다. 전체 제출물이 아니므로 공식 SDK와 run.py는 에이전트 팀이 합친다. `examples/agent_knowledge.py`와 `docs/agent-integration.md`를 참고한다.

## 검증 범위

현재 Python 테스트 55개 중 51개 통과, RDF/SHACL 4개는 의존성 미설치로 skip. JavaScript 문법 검사와 기존 그래프 테스트 통과. 공개 증례 검사는 진단 정답명을 사용한 오프라인 명칭·참고문서 검사이며 실제 진단 정확도 실험이 아니다. 합성 사례는 원본 KB 관계를 이용한 회귀 검사로 독립 임상 평가가 아니다.

HTTP handler는 소켓 없는 단위 테스트로 확인했다. 실제 소켓/브라우저 흐름은 로컬 연결 제한 때문에 확인하지 못했다. 실제 모델이나 팀의 개발 API 키를 사용하지 않았다. 완성도와 임상 성능을 검증 완료라고 표시하지 않는다.
