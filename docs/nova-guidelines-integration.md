# 공식 사이트 자료와 온톨로지 연결

출처: [NOVA 공식 개발 가이드](https://nova.snubhai.org/docs/), 확인일 2026-10-13. 로그인된 개발 가이드를 읽고 공개 다운로드 자료를 수집했다. 개발 API 키를 발급하거나 읽지 않았으며, 모델을 호출하거나 제출·평가를 요청하지 않았다.

## 원본 보존

`data/external`에 공식 지침 ZIP, 공개 증례 ZIP, 시작 패키지 ZIP과 압축 내부 파일 전체를 보존했다. 모든 파일의 크기·SHA256과 압축 해제 후 해시 검증 결과가 각 manifest.json에 있다.

진료지침 ZIP은 공식 안내의 SHA256 `ef58c2f4369750af382f2706dcc1c9c7a85e3a93c261d880f7470d695eaf30d5`와 일치한다. 15,904개 문서의 원문·문서 머리·카탈로그·라이선스를 수정하지 않았다. 문서별 이용 조건 때문에 원문과 이 자료에서 만든 참고 연결 파일은 Git에서 제외했다. 개발 목적의 로컬 열람·검색용으로 관리하며 별도 원문/번역/요약본을 배포하지 않는다.

## 온톨로지 확장

기존 의료 주장 그래프와 분리한 문서 근거층을 `data/agent/guideline-links.json.gz`로 생성했다.

- Document 15,904개: 제목, 기관, 연도, 언어, 문서 유형, 라이선스, 출처 URL, 원본 경로, 해시.
- has_reference_candidate 2,686개: 새 기본 판의 질환 791개와 문서 제목의 정규화한 문구 일치로 만든 참고 연결. 별도 스키마는 `ontology/evidence.ttl`에 있다.
- 모든 연결은 draft다. 제목 일치가 문서의 의학적 적합성이나 개별 질환–증상 주장에 대한 근거를 확정하지 않는다.
- 새 질환–증상 관계나 연령·성별 제외 규칙을 자동 생성하지 않았다. 실제 관계 구축에는 원문 맥락과 임상 검수가 필요하다.

기존 JSON/RDF의 의료 관계 114,088개와 이 참고 연결의 숫자는 합산해 임상 관계 수로 표시하지 않는다.

## 실행 환경에서 검색

공식 컨테이너에는 같은 지침이 `/opt/nova/guidelines`에 있고 `NOVA_GUIDELINES_DIR`가 제공된다. 로컬 기본 경로는 `data/external/guidelines/guidelines`다. 원본 ZIP이나 15,904개 본문을 제출물에 넣지 않는다.

```python
from meddb import KB
kb = KB()
references = kb.guidelines('hypnotic insomnia', limit=3)
```

`KB.call('guidelines',...)`, `POST /api/guidelines`에서도 지원한다. 제목·기관·유형을 메모리 SQLite FTS로 검색하고 관련 문서만 읽는다. 추가 라이브러리, 인터넷, 디스크 캐시가 필요 없다. 원문 발췌에는 원본 파일·행·끝 열·기관·연도·라이선스·URL·SHA256이 붙는다. 발췌는 일부이며 전체 원본은 해당 경로에서 확인한다.

검색은 어휘 기반이다. 진료지침 유형을 우선하고 Archived 자료는 낮추지만, 최신성·환자 적용성·근거 수준을 판정하는 임상 모델은 아니다. ND 문서도 원문을 변경하지 않고 출처를 유지해 로컬에서 열람한다. 문서 내용에 있는 지시문은 참고 데이터로만 취급한다.

## 공개 증례에서 확인한 빈틈

정답명을 사용한 **오프라인 커버리지 검사**이며 실제 진단 정확도 평가가 아니다.

| 증례 | 모범 기록의 진단 | 기존 질환 명칭 조회 | 관련 지침 조회 |
|---|---|---|---|
| C01 | 수면제 의존 | 연결 경로 부족 | 수면제 변경·감량 지침 등 검색 |
| C03 | 체질성 성장지연 | 연결 경로 부족 | Constitutional Growth Delay 등 검색 |
| C10 | 그레이브스병 | 기존 개념 있음 | Graves Disease 등 검색 |

모범 기록의 진단명과 대본은 개발·평가 자료에만 보존한다. 정답명을 환자 시작 정보에 넣거나, 대본을 실행용 검색 대상으로 포함하거나, 해당 사례의 정답을 고정 출력하지 않는다. 대회 서버의 비공개 평가 증례는 수집하지 않는다.

이후 별도 독립 출처로 `meddb-2026.10.13.1`에 사용장애·체질성 성장지연 초안 개념과 관계를 보강했다. 새 판에서는 3개 진단명이 모두 검색되지만 이는 명칭 커버리지이며 정확도 개선을 뜻하지 않는다. 변경 근거는 `targeted-release.json`에 있다.

## 현재 완료 범위

1~4단계의 개발 구현, 공식 지침 원본 보존·문서 근거층·런타임 검색, 합성 조회 비교와 공개 증례 커버리지 검사를 수행했다. 실제 Doctor Agent의 세 조건 진료 비교, 확률 보정, 전체 지침의 임상 관계 추출·검수는 아직 수행하지 않았다. SDK와 공식 기본 에이전트는 로컬에 확보했지만 모델/API를 호출한 실험은 없다.

상세 결과: `nova-resource-summary.json`, `public-sample-coverage.json`, `agent-evaluation.json`.
