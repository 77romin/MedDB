# 판단 범위를 구분하는 조건부 문진 관점

2026-10-18. 이는 임상 검수 완료된 진료 프로토콜이 아니라 Doctor에 제공하는 문진 범위 초안이다. 공개 증례 정답·대본·모범 기록을 추출하지 않았다. 어떤 소견·완료·처분도 코드로 확정하지 않고, 실제 응답과 현재 위험으로 적용 여부를 판단한다. 고정 질문을 강제하지 않는다.

## 설계와 근거

- **약물 노출:** 실제 최근 사용과 통상 사용, 약별 수치·시간 범위와 병용 범위를 구분한다. 의존/금단 관련 처방약 검토와 환자 참여에 관한 [NICE NG215 권고](https://www.nice.org.uk/guidance/ng215/chapter/Recommendations)를 참고한다. 성인 처방약 지침의 적용 범위를 넘어 감량 일정이나 응급 독성 용량을 만들지 않는다. 최근 24시간 구분은 노출 문진의 공학적 구조이며 이 지침의 특정 강제 시간 기준이라고 주장하지 않는다. 자해 평가는 적절한 경우 직접 확인한다는 [NICE NG225 1.13](https://www.nice.org.uk/guidance/ng225/chapter/Recommendations#safer-prescribing-and-dispensing)을 참고한다. 과량 노출과 의도는 별개다.
- **갑상선 치료 전 확인:** [ATA 임신 중 갑상선항진증 안내](https://www.thyroid.org/hyperthyroidism-in-pregnancy/)에 따라 임신 맥락이 해석·치료 선택에 영향을 줄 수 있음을 반영한다. [ATA 갑상선 안병증 안내](https://www.thyroid.org/thyroid-eye-disease/)에 따라 눈 증상과 흡연 맥락을 구분한다. 가설 상위 3개에 관련 명칭이 있을 때만 제공하며 확진을 뜻하지 않는다. 12–55세/연령 불명 조건은 누락 방지를 위한 개발상 넓은 활성 범위이며 생식 가능성을 판정하는 의학적 기준이 아니다. 남성으로 파싱되지 않았다고 임신 가능성이 있다고 기록하지 않는다. 약 종류·용량·치료 처방 규칙은 추가하지 않았다.
- **성장 경과:** [PES/AAP 체질성 성장 지연 안내](https://pedsendo.org/patient-resource/constitutional-growth-delay/)에서 부모 성인 키와 가족의 늦은 성숙 패턴을 구분하는 관점을 참고한다. 출처는 환자자료이며 단일 증상 확진 알고리즘이 아니다. 임의 성장속도 임계값·한국 성장도표 수치를 추가하지 않는다.

모듈의 활성화는 원문 키워드 휴리스틱이다. 부정·가족의 언급 때문에 불필요하게 활성화될 수 있고, 별칭 누락 때문에 비활성화될 수 있다. 활성 여부는 관찰의 참/거짓이 아니다. 기존 사실 추출의 시간·대상 의미 오류를 자동 교정하지도 않는다. 실제 질문·응답·판단과 비용은 API 비교에서 별도로 평가한다. 전체 자유 목표 개수를 늘리는 대신 제한된 범위 설명을 추가한 실험이다.
