## 복원

```sh
git clone --branch codex/nova-harness-rebuild https://github.com/SSAFY16-S11-NOVA2026/MedDB.git
cd MedDB/nova_harness
python3 tools/bootstrap.py
python3 -m unittest discover -s tests -q
```

표준 라이브러리 기반이며 Python 3.12를 권장한다. `bootstrap.py`는 해시가 고정된 공식 패키지를 복원한다. MedDB 비교 기능이 필요하면 README의 고정 커밋 checkout 절차를 추가로 따른다. 해당 선택 의존성이 없으면 overlay 테스트 하나는 건너뛴다.

개발 키는 별도로 프로젝트 로컬 `.env`에 설정한다. 키가 없는 상태에서도 단위 테스트·자료 검토·제출 준비를 진행할 수 있다. 제출 진입점은 `.env`를 읽지 않는다.

## Git에 포함한 것과 제외한 것

포함: 소스·테스트 fixture·출처·공개 대회 자료 정리·집계 보고·의사결정 문서.

제외: `.env`·인증정보·실행 원문 로그·소스 스냅샷 ZIP·다운로드 패키지·vendor checkout·생성된 제출 ZIP·캐시. 제출 ZIP은 필요할 때 도구로 다시 만든다. Git에 공개한 참고 자료·공개 예시가 진료 런타임으로 들어간다는 의미는 아니며 제출 허용 목록에도 포함하지 않는다.

로컬 프로젝트 테스트 49개, 원본 관련 테스트 11개가 통과했다. 키 없는 ZIP 독립 로딩과 무결성·키 제외를 확인했다. 새 프로젝트의 Docker·공식 서버 검증과 공식 점수는 미완료다.

별도 게시 경로 `nova_harness/`에서도 49개 테스트를 실행해 48개 통과·E2 overlay 1개 건너뜀을 확인했다. 선택 의존성 `vendor/meddb`를 게시하지 않기 때문이며, 원래 개발 폴더에서는 해당 테스트도 통과했다. 이 결과를 49개 전체 통과로 합쳐 보고하지 않는다.

공식 기준 67.132점은 기존 제출물 결과다. 최신 후보는 C01 비공식 검토에서 원본 E2를 넘지 못했다. 커밋·푸시는 재현 가능한 개발 이력을 공유하는 것이며, 성능 검증 완료나 공식 제출 권고를 뜻하지 않는다.

## 독립 개발 폴더에서 이어갈 때

현재 별도 개발 폴더를 계속 사용할 경우, 이 문서의 포함 목록을 `vendor/meddb-publish/nova_harness/` 게시본으로 복사한 뒤 해당 checkout에서 명시적 경로를 stage한다. `vendor/meddb/`는 비교·재현용 고정 커밋 `63743a8b8a2e278b426d18fc040e880740318ae3`로 유지한다. 게시용 checkout과 분리하여 브랜치 커밋 때문에 임포트의 고정 커밋 검증이 깨지지 않게 했다. vendor 전체나 개발 폴더 전체를 재귀 복사하지 않는다. 변경 내용과 `DECISIONS.md`를 함께 확인하고 테스트·비밀정보 검사를 거쳐 커밋한다. 원격 checkout의 `nova_harness/`를 직접 작업한다면 이 동기화는 필요 없다.
