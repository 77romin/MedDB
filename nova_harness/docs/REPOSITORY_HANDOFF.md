## 복원

```sh
git clone --branch codex/nova-harness-rebuild https://github.com/SSAFY16-S11-NOVA2026/MedDB.git
cd MedDB/nova_harness
python3 tools/bootstrap.py
python3 -m unittest discover -s tests -q
```

표준 라이브러리 기반이며 Python 3.12를 권장한다. `bootstrap.py`는 해시가 고정된 공식 패키지를 복원한다. MedDB 비교 기능이 필요하면 README의 고정 커밋 checkout 절차를 추가로 따른다. 해당 선택 의존성이 없으면 overlay 테스트 하나는 건너뛴다.

개발 키는 별도로 프로젝트 로컬 `.env`에 설정한다. 키가 없는 상태에서도 단위 테스트·자료 검토·제출 준비를 진행할 수 있다. 제출 진입점은 `.env`를 읽지 않는다.

## Git에 포함한 것과 제외한 것

포함: 소스·테스트 fixture·출처·공개 대회 자료 정리·집계 보고·의사결정 문서.

제외: `.env`·인증정보·실행 원문 로그·소스 스냅샷 ZIP·다운로드 패키지·vendor checkout·생성된 제출 ZIP·캐시. 제출 ZIP은 필요할 때 도구로 다시 만든다. Git에 공개한 참고 자료·공개 예시가 진료 런타임으로 들어간다는 의미는 아니며 제출 허용 목록에도 포함하지 않는다.
