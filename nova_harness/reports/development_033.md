# 33차 개발 보고 — R1 지침 벡터 RAG

2026-10-21 KST

## 구현 범위

원본 E2에 외부 지침 검색을 최종 기록 작성 시점에만 연결했다. 문진·진찰의 다음 행동 정책, 수렴 조기 종료, SOAP 원문 덧붙이기와 전역 교육 덮어쓰기는 변경하지 않았다. 기존 기록 생성 Doctor 호출에 근거 문맥을 추가하며 별도 Doctor 호출을 늘리지 않는다. 기록의 계획이 기존 종료 설명 입력으로 전달되므로 실제 설명 내용은 달라질 수 있다.

공식 코퍼스의 전체 문서 중 문서 유형이 진료지침·권고문·합의문인 4,488개를 일괄 선택했다. 공개 증례 ID·정답·대본을 사용하지 않았다. 운영 규칙·OT와 교과서·리뷰 등 나머지 문서 유형은 이 단계 색인에서 제외했다.

## 청킹·임베딩·저장소

최종 색인은 158,727개 청크다. 전체 테스트 186개가 통과했다. 제출 ZIP은 43,300,169바이트·52개 파일이고 SHA-256은 `d70e4e9c84afa6e47d79c0e3ac47ae0534f987f64bd6843a9b73d3b03f8b6a28`이다. 파일명은 `dist/submission_R1_rag_baseline.zip`이다.

- Markdown 절과 원문 행 범위로 청킹하며 짧은 예외·금기 문장을 버리지 않는다. 한 행이 매우 길면 경계를 보존하지만 런타임에서 7,000자 초과 발췌는 사용하지 않는다. 청크 경계가 모든 임상 문맥을 보존한다는 보장은 없으며 근거 적합성 검토는 계속 필요하다.
- 한국어 단어·2글자 부분어와 영어 단어의 TF-IDF에 TruncatedSVD를 적용한 64차원 LSA 임베딩이다. 해시 벡터도 사전학습 신경망 임베딩도 아니다. 문서와 질의에 같은 어휘·IDF·투영 행렬을 적용한다. 한·영 교차 의미 검색은 보장하지 않는다.
- SQLite에 어휘·IDF·투영, int8 청크 벡터와 출처 메타데이터를 저장한다. 검색 시 float32로 복원·정규화하고 NumPy로 정확 코사인 전수 검색한다. 별도 원격 DB 서버·ANN·MMR·LangGraph는 없다.
- 원문 본문은 ZIP에 복제하지 않는다. 서버의 `NOVA_GUIDELINES_DIR`에서 읽고 파일 SHA-256·경로·행 범위를 확인한다. 출처 URL·라이선스·발행기관·연도·청크 ID를 모델 문맥에 포함한다. 지침 파일이 없거나 바뀌면 해당 근거를 사용하지 않는다.

## 검색과 진료 연결

E2가 실제 관찰로 만든 상위 두 감별의 한·영 명칭을 검색어로 사용한다. 관련성 기본 임계값은 코사인 0.3이며 임상 확률이 아니다. 최대 60개 벡터 후보 중 중복 문서를 제외하고 최대 2개 발췌를 전달한다. 저차원 유사도만으로 무관한 드문 질환이 검색되는 사례를 발견해 실제 발췌문에도 구체적인 질의 단어가 있어야 통과하는 보수적 조건을 추가했다. 이 조건은 임상적 적합성의 증명이 아니다.

근거는 환자 관찰과 분리된 문맥으로 기록 생성 호출에만 제공한다. 실제 환자 S/O를 추가하지 말 것, 적용 대상·예외를 검토할 것, 기존 안전·추적 계획을 근거 없이 삭제하지 말 것을 명시한다. 사용한 근거의 `[RAG:chunk_id]` 표기와 조회·주입·인용 ID를 별도 계측한다. 인용 표시가 근거 충실성이나 실제 환자 전달을 증명하지는 않는다. 검색 실패나 결과 없음은 원래 기록 생성 경로로 복귀한다.

## 검증과 한계

테스트는 청크 원문 위치·짧은 예외 보존, 질의 투영·OOV, 원문 변조 차단·읽기 전용 DB, 기록 시점 주입·복구, 검색 결과 없음의 원본 호출 보존을 포함한다. 저장된 C01/C03/C10 전체 응답 재생에서 모든 호출을 소비했다. 최종 기록 호출 1회씩 두 증례에 근거가 주입됐고 한 증례는 검색 결과 없이 원본 경로를 사용했다. 저장 응답을 돌려주는 재생이므로 새 RAG의 답변 품질이나 점수 측정이 아니다.

영어 천식·당뇨·고혈압·불면/벤조디아제핀·갑상선항진 질의에서 관련 제목이 검색되는 것을 확인했으나, 연도·대상·최신성 선별과 짧은 한국어 질의는 약하다. LSA의 낮은 차원과 언어 연결 한계 때문에 일부 관련 근거를 놓치거나 용어만 겹치는 근거가 반환될 수 있다. 이 후보는 1단계 비교용이며 성능 개선이 입증된 추천본은 아니다.

최종 색인 재생성 후 추가 점검에서는 천식 지침은 잘 검색됐으나 갑상선항진 질의에 갑상선결절 지침, 벤조디아제핀 질의에 오피오이드 치료 지침이 포함됐다. 실제 발췌에 질의 용어가 있어도 적용 대상이 맞는다는 뜻은 아니다. 이것이 2단계에서 고쳐야 할 구체적 검색 품질 문제다. 최종 로컬 검색은 약 0.015–0.018초였고 해당 점검 프로세스 최대 RSS는 약 422MB였다. Linux 2코어 실행 성능으로 일반화하지 않는다.

ZIP CRC·명시적 허용 목록·독립 압축 해제 후 prepare를 점검했다. Docker daemon이 실행되어 있지 않아 Linux Docker 실행은 미검증이다. 이 회차의 live 개발 API 진료·새 모델 점수·공식 점수는 미측정이다. 사용자가 제공할 서버 샘플 결과로 대조군과 총점·6영역·턴·시간을 비교한다.

## 복원

기본 프로젝트 requirements는 기존 하네스용이며 R1 제출 ZIP은 `numpy==2.2.6`을 사용한다. 인덱스 생성에만 `tools/requirements-rag-build.txt`의 추가 의존성이 필요하다. 인덱스와 원문은 Git에 올리지 않는다.

```sh
python tools/build_rag_index.py --corpus /path/to/official/guidelines
python tools/package_rag_r1.py
python -m unittest discover -s tests -q
```
