# 36차 개발 보고 — R3a 환자 적용 적합성 선별

2026-10-21 KST

## 범위

사용자가 35차 검토의 R3 진행을 승인했다. 이번 후보는 세 역할을 동시에 바꾸지 않고 **근거 적합성 선별 역할만** 추가하는 R3a다. 검색 요청 작성 프롬프트와 별도 생성 역할 재설계(R3b/R3c), LangGraph는 이번 ZIP에 없다.

사용자가 측정한 R2 ZIP을 동결 기반으로 사용했다. R2의 SQLite 인덱스·임베딩·검색 코드·질의 생성·기록 생성 프롬프트는 바이트 단위로 같다. 패키지 변경은 `run.py`의 오버레이 연결·감사 로그와 두 파일 `rag_selector.py`, `e2_rag_selection.py` 추가뿐이다.

## 동작

기존 기록 생성 시점에 R2 검색 후보 최대 2개를 얻는다. 실제 시작 정보·활력징후·환자 발화·진찰 결과와 검색 문서를 별도 자료 필드로 Doctor에게 제시하고 `usable/rejected/uncertain`으로 분류한다. 의사 질문은 답변의 문맥으로만 제공하며 환자 사실의 인용 대상으로 쓰지 않는다. 임의 나이·복용약·음성 소견을 새로 만들지 않도록 지시한다.

usable 후보는 실제 관찰 ID·정확한 관찰 인용·정확한 원문 발췌 인용을 요구한다. 코드가 후보 ID·중복·누락·출처와 인용의 원문 일치를 검사한다. 후보 밖 출처, 만들어낸 인용, 미완성 JSON은 모두 미사용으로 처리한다. 원문 일치는 모델의 임상 적용 판단이나 부분 부정 해석이 맞음을 보증하지 않는다.

선별기가 반환할 수 있는 것은 원래 검색된 문서의 부분집합뿐이다. 모델이 쓴 환자 주장·지침 요약·판단 이유는 기록 생성 입력에 추가하지 않는다. 통과된 원문 문서만 R2와 동일한 기존 생성 프롬프트로 넘긴다. 전부 rejected/uncertain이면 기존의 지침 없는 기록 경로로 복귀한다. 문진·진찰 행동 선택은 변경하지 않는다.

## 예산과 상태

- 증례당 논리적 선별 호출 최대 2회, 호출당 출력 상한 1,536토큰. 별도 재시도 루프 없이 오류는 근거 미사용이다.
- 남은 시간이 240초 미만이면 선별을 건너뛰어 기존 기록 작성 여유를 보호한다. 모든 모델 호출·토큰 잔여량을 정밀 예측하는 기능은 아니다.
- 실제 관찰·질의·후보 원문 전체의 SHA-256으로 캐시한다. 동일 입력은 재호출하지 않고 관찰이 바뀌면 예전 판단을 그대로 재사용하지 않는다. 호출 상한에 도달했으면 새 관찰은 지침 미사용으로 처리한다.
- 설치마다 호출·캐시 상태를 초기화하고 완료 후 원래 함수를 복구한다. 선택 결과·사유·관찰 ID·호출 횟수·실패 유형은 로그에 기록하며 개발 키·실행 원문은 Git에 넣지 않는다.

## 검증

전체 테스트 192개 통과. 새 항목은 의사 질문의 환자 사실 승격 방지, 원문 문서 부분집합 보장, 후보 밖 ID·조작 인용·누락·중복 거절, rejected/uncertain 제외, 입력 변경 시 캐시 분리, 증례 호출 상한, 시간 보호, 실패 재시도 방지를 포함한다.

세 저장 증례에 synthetic accept-all과 uncertain-all 선별 응답을 각각 적용한 총 6개 재생을 완료했다. 여섯 경로 모두 저장 API 호출을 끝까지 소비했고, 합성 선별 호출은 각각 1회였다. 이 결과는 합성 선별과 저장 Doctor 응답을 사용한 연결 검증이며 실제 선별 정확도나 점수 측정이 아니다. `tools/replay_rag_r3a.py`로 재현한다.

ZIP CRC·50MB 제한·독립 압축 해제 후 prepare·오버레이 설치/복구를 확인했다. R2 대비 인덱스·검색·기록 생성 코드가 동일함을 확인했다. Docker·서버 공식 점수는 미검증이다.

## 실제 개발 API 1회

실행 `20261021_221113_840398_meddb_e2_rag_selection`은 서버 기록 최대 44턴·352.118초로 정상 종료했고 `수면제 의존(진정수면제 사용장애)`를 제출했다. Doctor 성공 요청 20회, 입력 36,813·출력 9,163토큰이었다. 이 단일 실행을 진단 정확도나 공식 점수 개선으로 일반화하지 않는다.

선별은 기록 작성과 재작성에서 총 2회 실행됐다. 첫 응답은 원문 검증을 통과했으며 정의 설명만 있는 문서를 uncertain, 62세 성인에게 맞지 않는 소아·청소년 불안 선별 문서를 rejected로 분류했다. 두 후보 모두 제외했다. 두 번째 응답도 상태는 uncertain/rejected였지만 source_quote가 실제 원문과 일치하지 않아 코드 검증에서 거절됐다. 로컬 저장 요청/응답으로 검증을 다시 실행해 `invented source quote` 조건에서 막힌 것을 확인했다. 표현·부분인용 불일치가 곧 의도적 사실 조작이라는 뜻은 아니다. 검증 조건은 완화하지 않았다.

최종 기록 생성에는 외부 지침 0개가 전달됐다. 부적합 자료의 차단은 확인했지만 이 실행에서 올바른 지침을 활용한 성능 이득은 입증하지 못했다. 선별이 기존 후보에 없던 올바른 문서를 만들어낼 수 없다는 한계도 남는다. 문진 중 `EXAM_NOT_SPECIFIC` 거절 1건이 있었으며 선별 역할과 별개인 기존 진찰 표현 문제다. 출력 절단은 0건이다. 원문 로그와 인증정보는 Git·제출 ZIP에서 제외했다.
