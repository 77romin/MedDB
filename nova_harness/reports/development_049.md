# 49차 개발: 자유 질문의 보수적 target 연결

## 승인·구현

D091 승인에 따라48차 R3a_coverage_order의 문진 순서/검색/기록/마무리를 고정하고 `R3a_question_link` 후보를 추가했다. 기본 실행 경로는 바꾸지 않았다. 원본 MedDB도 수정하지 않는다.

질문 생성의 기존 pick ID와 표준 질문 일치 경로를 유지한다. 자유 질문 target이 없을 때만 finite 어미 변형을 정규화해 기존 DB 질문에 유일하게 연결한다. 기간·시점·부정·주어·나머지 본문을 삭제하지 않는다. 여러 target이 일치하거나 복합/과거 경험 범위이면 보류한다. DB의 연령·성별 적합성을 적용하며 complaint-specific extra 질문의 적합성을 확대하지 않는다. 약 복용 여부·이름·용량을 합치지 않는다.

질문 원문이 target에 연결되면 기존 중복/적합성 검사를 거친 뒤 실제 SAY를 보낸다. 성공 답변을 받은 경우에만 원문 질문·답변·턴과 연결 근거를 보관한다. 제안/실패 요청은 성공 근거가 아니다. 소견 양성/음성/미확인은 기존 read_answer를 그대로 사용한다. 따라서 새 연결이 소견 target에 실제 발생하면 기존 해석 호출이 추가될 수 있다. 의미 연결용 별도 LLM 호출이나 새로운 진단 규칙은 추가하지 않았다.

원본 모듈의 target 추론 블록을 정확히1개 확인한 뒤 별도 모듈로 컴파일하는 가역 오버레이다. 계약이 다르면 실패하고 종료하며 원본 파일을 덮어쓰지 않는다. 설치 순서는 R3a 검색→응답 상태→문진 순서→질문 연결→수동 기록 관찰, 복원은 역순이다.

## 48차 C10 해석 보완

48차 감사는 실제 기침 주제의 질문/답변 존재를 확인했다. 하지만 원문을 더 엄격히 보면 자유 질문은 과거 경험을 묻고 표준 target은 현재 지속 여부를 묻는다. 두 질문이 동등하다는 검증은 아니었다. 이번에는 그 자유 질문을 historical_scope로 보류한다. '그런 적 없다'를 현재 지속 증상의 음성 근거로 강제 등록하지 않는다.

마찬가지로 '설사를 자주 하는가'의 부정은 일반 설사 부재와 같지 않으므로 본문에서 빈도 제한을 지워 연결하지 않는다. 표현은 달라도 항상 같은 임상 의미라는 전제는 잘못된 연결을 만들 수 있다.

## 테스트·저장 관찰 검증

전체 회귀280개 통과. 새13개 테스트는 의미가 같은 현재 지속 질문 연결, 실제 과거 경험 질문 보류, 숫자/부정/주어 변경 보류, 복합 질문/진술문 거절, target 충돌 보류, 약물 개념 분리, 인구학 필터, 출처 원문 보존, 기존 중복 차단과 복원을 다룬다. 합성 전체 진료 통합에서 성공 응답만 기존 해석기로 반영되고 실패 요청·과거 범위는 현재 소견의 음성 근거로 들어가지 않음을 확인했다. 이것은 합성 경로 검증이며 실제 환자 효과가 아니다.

48차6개 실제 세션의 성공 발화 중 target 없는73건을 재분류했다. not_single_question42, compound11, unmapped19, historical_scope1이며 새 연결0이었다. 의사 설명·마무리 질문도 포함된 집합으로73개 임상 질문의 실패라는 뜻이 아니다. 이 검증에서 연결 회수율 향상은 입증되지 않았다. `question_link_observation_replay_049.json`에 원문 없이 기록했다.

48차 후보3세션 전체를 새 계층으로 엄격 재생해 모델 입력·행동·최종 SOAP와 저장 응답 소진이 모두 같았다. 새 계층의 보류가 기존 경로를 바꾸지 않은 검증이지 신규 연결 효과 검증이 아니다. `question_link_session_replay_049.json`에 집계했다.

## 결론과 다음 범위

구현·실패 차단·기존 경로 호환 검증은 완료했지만 연결 회수율/공식 점수의 개선은 입증되지 않았다. 기능은 별도 후보로만 보존하고 성능 개선본에 채택하지 않는다. 새 제출 ZIP·공식 업로드·병합은 하지 않았다. Docker·공식 환경·일반화 성능은 미검증이다. 원문 로그·환자 인용·키는 Git에 포함하지 않는다.

근본 제약은 좁은 어미 변형으로 자유 질문의 의미·질문 범위를 충분히 연결할 수 없다는 점이다. 무리하게 동의어·수식어를 지우면 '자주 없다'를 '없다'로 바꾸는 오류가 생긴다. 다음 별도 실험은 일반 증상·빈도·기간·과거/현재·대상·부분 응답을 분리한 질문 계약과 미확인 상태다. 특히 기존의 복합 질문 target에 일부 증상만 답한 경우 전체를 음성으로 확정하지 않아야 한다. 이 구조 변경은 이번 패치에 섞지 않았다. 현재 후보나 R3a를 공식 샘플에서 재측정하기 전 고득점 후보·78점 예상으로 표현하지 않는다.
