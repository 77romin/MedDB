- 크기: 43,323,736 bytes, 61 files
- SHA-256: `1be9a5e74e166515f2103ec7a58d0d9c65396dcfa09f023fd79c5e5978614c81`
- 기준: 동결 R3a `73570513ccda66c360ade7d73a6b415a56667748cc607d10442cdd57a3500dc8`

R3a 기존 파일 중 run.py만 연결을 변경했다. 안전 모듈 6개는 최종 개발 소스와 바이트가 같다. repair_invalid=True 및 질문 차단을 활성화하고 구조화된 의무 렌더러를 사용한다. R3b 쿼리 계획이나 R4 LangGraph는 추가하지 않았다.

압축 CRC·50MB 제한·경로/비밀 파일 제외·기준 자산 불변을 확인했다. 임시 폴더로 압축 해제 후 실제 prepare와 consult 연결을 가짜 진료 함수로 검사하고 원래 기록 함수를 복원함을 확인했다. 임상 성능 테스트가 아니며 기존 의존성 환경을 사용했다. 깨끗한 설치·Docker·공식 실행은 미검증이다.

최종 임상 실측 및 남은 안내 누락은 development_044.md를 따른다. 신규 API 세션·공식 업로드는 실행하지 않았다. 사용자 공식 영역별 점수를 받은 뒤 R3a와 비교한다.
