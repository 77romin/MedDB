## 본문과 근거

- 메인 README를 위 순서와 후속 고찰·결론으로 재편했다. 이전 전문은 `docs/research/README_2026-10-23.md`에 보존하고 상대 링크를 조정했다. 전수 실험 목록·15개 점수 원자료·기존 온톨로지 화면과 생성 자산은 유지했다.
- 체크아웃에 원문 results/trace·관찰 로그·starter/SDK가 없는 것을 확인했다. 공개 집계 JSON과 당시 재생 결과·보고서만으로 감사 가능한 항목을 제한했다. 원문 문장별 SOAP 의미 감사·독립 임상 평가를 수행했다고 주장하지 않는다.
- `tools/build_retrospective_audit.py`는 공개 세션 ID 대응·합계를 검사하고 현재 reader→Tracker→S 초안에 합성5사례를 실행한다. SDK·LLM·네트워크를 사용하지 않는다. 실제 진료·최종 LLM SOAP와 합성 시연을 구분한다.
- `docs/paper/retrospective_audit.json`에 자료·소스 해시, 69개 reader 관찰의15/45/9 분포와 신규 단일 응답 연결0, B1/B1O1 개발 대조, 과거 전달 그룹0/11·0/7·9/11, 합성5사례와 미측정 null 항목을 남겼다.
- 실제 처리 근거는41차 보고서·저장 응답 재생 집계의23자/28자 경고 소실·보존 사례로 보강했다. 공개 자료에 없는 실제 경고 문장을 만들어 인용하지 않는다. S1·52차 미채택 후보와 최종 B1O1을 구분한다.

## Excalidraw

기존148개 요소를 `before-meddb-paper-20261108` 스냅샷으로 보존했다. 기존 작업을 지우지 않고 x=3000..4900 영역에 최종 아키텍처, 처리 사례, 후향적 감사, 핵심 서버 샘플 점수의4개 그림을 추가했다. MCP로 배치 생성·스크린샷 확인·수정·PNG/SVG 내보내기를 수행했다. 각 `.excalidraw`에는 해당 그림의 요소만 담아 다른 프로젝트의 기존 캔버스를 공개 자산에 포함하지 않았다.

그림4의0폭 격자선이 대각선으로 정규화되는 현상을0.01폭으로 고쳐 재확인했다. 모든 그림에서 한글·간격·화살표를 확인했다. 한글 출력은 시스템 폰트 대체를 사용하므로 환경 간 폰트 차이가 있을 수 있다. 브라우저 뷰포트 이동 요청은 시간 초과했지만 서버 기반 렌더·내보내기는 성공했다. 외부 공유 URL 업로드는 수행하지 않았다.

`assets/retrospective/manifest.json`에 그림별3개 형식·해시·요소 수·PNG 크기·근거 경로를 남겼다. 기존5개 논문 그림과 생성기는 보존했다.
