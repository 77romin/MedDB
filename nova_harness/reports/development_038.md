# 38차 개발 보고 — R3b 관찰 기반 검색 요청 작성

2026-10-21 KST

## 범위

사용자가 다음 단계 진행을 승인했다. R3a 서버 샘플 76.290점·안전 15점의 ZIP을 복구점으로 보존하고, 검색 요청 작성 역할만 추가한 R3b를 별도 패키지로 만든다. R3a의 적합성 선별·원문 인용 검사·실패 시 지침 미사용, R2 검색 구현, 임베딩·인덱스, 기존 기록 생성 프롬프트는 바이트 단위로 동일하다. 문진·진찰 선택과 R3c 생성 재설계·LangGraph는 변경하지 않는다.

## 검색 요청 작성

기존 검색은 구조화 후보 상위 두 질환의 한·영 명칭만 사용한다. R3b는 기록 작성 시 실제 환자 관찰과 그 후보 문자열을 구분해 Doctor에 제공하고, 치료 안전·치료 방향·추적·진단 확인 중 한 가지 미해결 임상 질문과 짧은 검색어를 작성한다. 영어 위주 코퍼스에 맞춰 영어 의학 용어를 권장하지만 실제 임상 번역의 정확성을 코드가 보증하지 않는다.

검색어 240자, 임상 질문 160자, 실제 관찰 ID·정확한 원문 인용 최소 1개, 의도 enum을 검증한다. 의사 질문은 관찰 인용 대상으로 인정하지 않는다. query가 비어 있으면 기존 질환명 검색을 사용한다. 모델이 쓴 임상 질문·새 환자 주장·요약은 SOAP 생성 입력에 추가하지 않고, 검증된 검색어만 동결 검색기에 전달한다. 인용의 원문 존재만으로 검색어에 쓰인 모든 임상 개념이 적절함을 보증하지는 않는다.

새 검색 결과는 반드시 기존 R3a 적합성 선별을 거친다. 새 검색에 결과가 없으면 기존 검색어로 후보를 다시 얻고 같은 선별을 수행한다. 새 검색에 후보는 있으나 선별에서 모두 제외되면 지침 없이 기존 기록을 작성하며, 무제한 재검색하지 않는다.

## 호출·실패 제어

- 새 요청 작성 호출은 증례당 최대 1회·출력 1,024토큰이며 별도 재시도 루프가 없다. 기존 R3a 선별 호출 최대 2회는 유지한다.
- 실제 관찰과 원래 검색어의 전체 해시를 캐시한다. 동일 입력은 재사용하지만 기록 이후 관찰이 달라지면 이전에 만든 요청을 그대로 재사용하지 않고 기존 질환명 검색으로 돌아간다.
- 남은 시간이 330초 미만이면 새 역할을 건너뛰어 기존 선별·기록 여유를 보호한다. 응답 파싱·인용·API 실패는 기존 검색으로 복귀한다.
- 요청 생성·캐시·실패·검색 결과 없음 복귀·후보 ID를 별도로 계측한다. 원문 로그·개발 키는 Git·ZIP에서 제외한다.

## 검증

전체 테스트 197개 통과. 새 테스트는 요청·의도·길이 검증, 관찰 ID/인용 조작 거절, 빈 요청, 단일 호출·동일 입력 캐시·변경 관찰의 기존 검색 복귀, 새 검색 결과 없음 복귀, 시간 부족·API 실패 처리를 포함한다.

세 저장 증례에 유효한 합성 요청/통과 선별과 잘못된 합성 요청/제외 선별을 각각 적용한 총 6개 연결 재생을 완료했다. 추가 요청·선별 각각 1회였고 저장 API 호출을 모두 소비했다. 합성 요청/선별과 저장 Doctor 응답을 사용했으므로 실제 임상 검색·선별 정확도나 점수 측정이 아니다. `tools/replay_rag_r3b.py`로 재현한다.

ZIP CRC·50MB 제한·독립 prepare·오버레이 설치/복구를 확인했다. R3a 대비 신규 2개 모듈과 `run.py` 연결/로그만 다르며 기존 모든 파일은 동일하다. Docker·R3b 서버 샘플 점수는 미검증이다.

## 실제 개발 API 1회

실행 `20261021_225024_038543_meddb_e2_rag_query`는 최대 45턴·392.851초로 정상 종료하고 `갑상샘항진증(그레이브스병)`을 제출했다. Doctor 성공 요청 29회, 입력 37,105·출력 7,482토큰, API/행동 오류·출력 절단 0건이었다. 단일 공개 증례 결과이며 진단 정확도·일반화·공식 점수 개선을 검증한 것은 아니다.

검색 요청 역할은 실제 진찰 관찰 `t38/t39`를 인용해 `thyrotoxicosis diagnosis TSH free T4 T3 TRAb diffuse goiter thyroid bruit`를 생성했다. 검색은 후보 2개를 반환했다. 기존 R3a 선별은 초기 평가·원인 확인 지침 1개를 usable, 추가 검사 맥락이 부족한 다른 후보를 uncertain으로 분류했고 원문 인용 검증을 통과했다.

`The Diagnosis and Management of Hyperthyroidism in Korea: Consensus Report of the Korean Thyroid Association`의 청크 `15737853935c9f23970e36b8` 1개가 기존 기록 생성 호출 1회에 제공됐고 최종 기록에서 해당 ID 인용을 확인했다. 잘못된 인용 ID는 0개였다. 이는 이 실행의 검색·선별·인용 연결 확인이며 각 임상 권고의 정확성이나 실제 환자에게 충분히 설명됐다는 보증은 아니다. 요청 작성 1회·선별 1회였고 생성 요청 실패·기존 검색 복귀는 없었다. 원문 로그는 로컬에만 보존한다.
