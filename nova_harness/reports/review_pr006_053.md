## 권고 실험: 검색 고도화보다 문진 정책 대조 먼저

우선 별도 후보에서 **우리 관찰 상태 + 모델 주도 질문 선택**을 결합한다. 온톨로지는 현재 근거·감별에 필요한 후보/누락 영역·표준 진찰·안전 제약을 공급하고, 매 턴 모델이 '어떤 미확인 내용을 왜 물을지'와 질문 하나를 제안한다. 근거 없는 확진/정상화·응답 완료와 소견 진실성 혼합을 금지한다. 위험 신호 확인은 단순히 모델 자유 선택에 맡기지 않는다. 점수 share는 진단확률로 부르지 않는다.

질문 정책과 마무리 구조를 동시에 바꾸지 않는다. 첫 비교는 종료 정책/검색/기록/마무리를 고정하고 질문 선택만 바꿔 효과를 분리한다. 이후 별도 비교로 설명 예산과 임상 행동 타입 기반 그룹 렌더러를 평가한다.52차 실패한 원문 action 문자열 일치 계약을 그대로 늘리지 않는다. 조기 종료·능동 감별 수렴은 이번 검토에서 도입하지 않는다.

측정은 동시점 기준/후보를 같은 공개 증례에서 반복 실행하고, 획득한 유효 사실·부분/모호 응답 처리·답변 후 반복·구체화 질문·진찰 거절·중요 안전 조건 실제 전달·미발화 수행 기록·턴/호출 비용을 비교한다. 개발 API 분석과 공식 샘플/리더보드 점수를 분리한다. 양쪽 실제 로그와 동일 평가 결과를 확보하기 전 개선/78점 기대를 확정하지 않는다. 팀원 원문 임상 로그를 공개 보고서에 복사하지 않는다.

이번 작업은 정적 비교/권고 문서화다. 런타임·기본 후보·제출 ZIP·PR6는 수정하지 않았고 테스트/API를 실행하지 않았다. 구현은 사용자 검토 후 진행한다.
