## R2 변경 범위

R1 ZIP의 인덱스·임베딩·질의 구성·생성 프롬프트·의존성·문진·진찰 흐름을 고정했다. `run.py`의 저장소 import와 `nova_agent/rag_retrieval.py` 추가만 패키지 차이다. MMR·세 역할 프롬프트·LangGraph는 포함하지 않는다.

검색 정책을 하나의 묶음으로 교체한다. 각 검색 요소의 단독 인과 효과를 별도로 측정한 것은 아니다.

1. 기존 코사인 상위 200개와 제목·절 제목의 SQLite FTS5/BM25 상위 200개를 결합한다. FTS5가 없으면 메타데이터 용어 겹침으로 복귀한다. 원문 본문 BM25 인덱스는 아니다.
2. Reciprocal Rank Fusion으로 후보를 모으고 제목·본문·절 제목의 IDF 가중 용어 충족도와 코사인으로 재정렬한다. 낮은 코사인이라도 실제 제목과 본문이 같은 질의 용어를 지지하면 희귀 질환 후보를 회수할 수 있다.
3. 본문에 잠깐 언급됐다는 이유만으로 다른 질환 지침을 선택하지 않도록 제목의 구체적인 용어 일치를 요구한다. 참고문헌·이해상충·연구비 등 절은 제외한다.
4. 파일 경로·해시 확인과 결과 최대 2개·동일 경로 문서 중복 제거를 유지한다. 동점에만 최신 연도를 우선한다. 환자 연령·임신·중증도 기반 적용 대상 필터는 아직 없고, 최신 지침 우선도 완전하지 않다.

## 검증

전체 테스트 187개 통과. 새 합성 fixture는 높은 코사인의 무관한 제목/참고문헌을 제외하고 낮은 코사인의 실제 관련 문서를 어휘 검색으로 회수하는지, 반복 실행 결정성, FTS5 부재 fallback, 원문 변조 차단, 일반어 질의의 결과 없음을 점검했다.

저장된 세 증례 응답을 R2로 끝까지 재생했다. 세 증례 모두 근거 2개씩을 기존 기록 생성 호출 1회에 제공했고 나머지 호출은 저장 원본 요청과 일치했다. 저장된 모델 답을 반환하는 재생이므로 새 진단·SOAP의 임상 품질이나 점수 측정은 아니다.

10개 고정 개발 질의의 R1/R2 비교는 `retrieval_034.json`에 보존한다. R1 실패 사례를 보고 만든 점검 질의도 포함하므로 독립 평가·검색 정확도 추정으로 표현하지 않는다.

| 질의 | R1에서 발견한 문제 | R2 결과 |

| Graves hyperthyroidism | 갑상선결절·골건강 지침 | 갑상선항진 진단·관리 및 방사성요오드 지침 |

| 성장 지연 | 아토피·수혈 관련 문서 | 결과 없음으로 안전하게 미사용 |

천식·결핵·편두통 검색은 관련 제목을 유지했다. 반면 고혈압은 2013년 문서가 상위이고, 간질에서는 소아·특정 유전질환 문서가 남는다. 제목 관련성이 곧 환자 적용 적합성을 의미하지 않는다. R2 검색 시간은 로컬 점검에서 약 0.013–0.056초였으며 운영 환경 성능 보장은 아니다.

## 제출 후보와 다음 판단

`dist/submission_R2_retrieval.zip`은 R1 대비 검색만 바꾼 2단계 비교용이다. ZIP 무결성·독립 prepare와 동결 자산 동일성을 확인했다. Docker·live 개발 API 진료·R2 서버 점수는 미검증이다. 사용자가 제출 후 영역별 점수·턴·시간을 공유하면 R1과 비교한다. 검색 개선을 안전·정보수집 개선으로 미리 인정하지 않는다. 결과 확인 전 R3 역할 프롬프트 후보를 만들지 않는다.

ZIP은 43,302,838바이트·53개 파일이며 SHA-256은 `d70caa527f4ba6392d9488369b0d4f6d1442843198bd71e70222530db599d041`이다. R1과 인덱스·기록 생성 코드의 바이트 동일성을 확인했다. 재생 검증은 `tools/replay_rag_r1.py --retrieval r2 ...`, 검색 비교는 `tools/compare_rag_retrieval.py`로 재현한다. 패키징 도구는 사용자가 측정한 R1 ZIP 해시를 요구한다.
