# 개발 17차 — 약물 안전 후보 API 검증

2026-10-19. `meddb_e2_med_safety`를 공개 C01 개발 API에서 실행했다.

실행 `20261019_181557_595782_meddb_e2_med_safety`는 45턴, 297.7초, Doctor 성공 호출 14회, API 오류 0건으로 완료했고 진단은 수면제 의존으로 일치했다. 추가 수면제·음주·직접 운전 회피와 깨우기 어렵거나 호흡이 느릴 때 119 연락은 실제 `SAY`로 전달됐다. 반면 비약물 치료 질문에는 `검사 결과를 보고 자세히 알려 드릴게요.`가 전송돼 직접 답변 보완은 작동하지 않았다. 출력 절단도 1건 발생했다.

개발 평가 추정은 정보수집 19, 진단추론 13, 검사·추적 6, 안전 7, 의사소통 8, 효율 12, 총 65점이다. 원본 동시점 C01 64점, 약물 재확인 후보 66점과 비교해 의미 있는 상승이 아니며 효율은 더 낮았다.

안전 문장을 실제 전달해도 갑작스러운 중단 위험, 감독하 감량, 당일 평가·보호자 동행은 기록에만 남았다. 우울감과 약물 목록 질문도 반복됐다. 따라서 이 후보는 폐기하고 C03/C10으로 확장하지 않는다. 다음 후보는 질문을 추가하지 않고 중복 질문을 제거한 턴을 감량 원칙, 추적 계획, 비약물 치료 답변에 재배정해야 한다.
