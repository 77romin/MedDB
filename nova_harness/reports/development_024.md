# 24차 개발 보고 — 온톨로지 압축 SOAP와 고가치 질문 분리 실험

2026-10-20 KST

## 목적

Evidence Ledger 제출의 공식 샘플 점수 76.634에서 원본 E2 77.714보다 정보수집과 의사소통이 낮아진 원인을 분리한다. 원문 근거는 내부 ledger에 보존하되 SOAP의 중복 원문을 줄이고, 현재 관찰과 의료지식이 진단·중증도·치료 결정을 바꾸는 질문을 먼저 선택한다.

## 구현

### 압축 SOAP 단일 변경

`e2_concept_compaction`은 원본 E2의 기록 모델이 전체 transcript와 의료지식으로 만든 구조화 SOAP를 그대로 둔다. 그 뒤 `CareCoverage.append_record()`가 같은 질문과 원문 답을 다시 HPI/PMH에 붙이는 단계만 제거한다. 환자 원문은 ledger와 transcript에 남아 감사할 수 있다. 증상 개념의 부정·대상·시간·속성을 잃는 단어 치환은 하지 않는다.

### 고가치 질문 단일 변경

`e2_value_questions`는 기존 질문·진찰 후보를 다음 순서로 재평가한다.

1. 상충 진술 확인
2. 위험징후 확인
3. 상위 감별진단의 미확인 핵심 소견
4. 치료 안전과 약물 노출
5. 객관적 진찰
6. 일반 병력과 배경 정보

동일 target은 한 번만 남긴다. 불면증이고 수면제 사용이 실제 관찰된 경우에만 정제 함량, 마지막 복용 시점·개수, 24시간 총량, 복수 처방, 다른 수면유도제·진정제 사용을 후보에 추가한다. 이 조건은 공개 증례 ID나 정답을 사용하지 않는다.

## 결론과 다음 게이트

압축 SOAP와 가치 질문의 가역 구현은 완료했고 전체 테스트는 통과했다. 그러나 둘 중 어느 것도 원본 E2보다 공식 점수가 높다는 근거는 아직 없다. 최종 가치 질문 소스는 개발 API에서 실제 행동을 한 번도 수행하지 못했으므로 C03·C10 확대, 두 기능 결합, 제출 ZIP 생성을 보류한다.

다음 유효 C01 실행에서 아래 조건을 먼저 확인한다.

- 다섯 약물 안전 질문이 수면제 사용 확인 뒤에만 실제 실행되는가.
- 응답이 구조화 기록과 최종 SOAP에 간결하게 반영되는가.
- 동일 의미 질문이 반복되지 않는가.
- 핵심 진찰, 감독하 감량·추적, 안전망, 환자 질문의 직접 답변이 밀리지 않는가.

이 조건과 비공식 영역별 회귀 검토를 통과하면 C03·C10으로 확장한다. 실제 의사소통 발화는 압축·질문 정책과 섞지 않고 이후 별도 단일 변경으로 비교한다.
