# 23차 구현 계획 — 온톨로지 임상 개념과 고가치 질문 순환

2026-10-20. 사용자가 제안한 두 개의 축을 하나의 순환으로 구성한다. 환자 응답을 온톨로지 개념으로 구조화해 압축 SOAP에 기록하고, 같은 개념의 미확인 속성과 진단·중증도·치료 결정 가치로 다음 질문을 선택한다.

## 임상 개념 자료구조

단순 단어 치환이 아니라 다음 필드를 보존한다.

```json
{
  "concept_id": "meddb:diarrhea",
  "label": "설사",
  "assertion": "present",
  "subject": "patient",
  "temporality": "current",
  "onset": "recent",
  "frequency": "frequent_qualitative",
  "trigger": "postprandial",
  "severity": "unknown",
  "evidence_id": "e17",
  "quote": "요즘 밥을 먹으면 화장실에서 물똥을 자주 싸요"
}
```

- `assertion`: present/absent/uncertain/unknown. 부정을 양성으로 바꾸지 않는다.
- `subject`: patient/family/other. 가족 증상을 환자 병력으로 옮기지 않는다.
- `temporality`, `onset`, `duration`, `frequency`, `severity`, `trigger`: 원문에 있는 것만 저장하고 나머지는 unknown으로 남긴다.
- `evidence_id`, `quote`: 원문은 내부 감사에 보존하되 SOAP에 반복 출력하지 않는다.

## 압축 SOAP 렌더링

- `요즘 들어서 입맛이 없어서 밥을 많이 안 먹었다` → `식욕저하(+), 최근; 섭취량 감소(+) [e12]`
- `요즘 밥을 먹으면 물똥을 자주 싸요` → `설사(+), 최근·식후·빈번; 정확한 기간/횟수 미확인 [e17]`
- `우유만 먹으면 배가 아픈 것 같기도 해요` → `우유 섭취 후 복통(?), 불확실 [e21]`
- `설사는 없고 오히려 변비예요` → `설사(-), 변비(+) [e25]`

문장에 없는 진단·원인·정확한 횟수는 추론해 넣지 않는다. `식욕부진`은 질환명이 아닌 증상 개념 `식욕저하`로 표준화한다.

## 고가치 질문 선택

구조화된 개념이 들어오면 온톨로지에서 연결된 미확인 속성·위험징후·진단 분기를 후보로 만든다. 각 질문의 점수는 다음과 같다.

`value = 5·응급도변경 + 4·주진단분기 + 3·치료결정 + 2·검사/추적결정 + 정보공백 - 중복비용 - 연관성부족`

- 응급도 변경: 현재 처치 장소나 즉시 대응을 바꿀 수 있는가.
- 주진단 분기: 상위 진단 후보의 순위를 바꾸는가.
- 치료 결정: 약물·비약물·입원·의뢰 선택에 필요한가.
- 정보 공백: unknown/uncertain/conflict인 핵심 속성인가.
- 중복 비용: 이미 present/absent로 확인한 target은 기본 차단하고, 부분·상충일 때만 재질문한다.

상위 1개만 실행한다. 질문 실행 후 답변을 개념으로 갱신하고 점수를 다시 계산한다. `설사`가 확인되면 일반 감별 질문을 늘어놓기 전에 탈수·혈변·발열·기간과 같이 중증도와 분기를 바꾸는 정보를 비교한다.

## 안전 장치

- 온톨로지 매핑은 원문을 덮어쓰지 않는다. 요약에서 원문으로 역추적할 수 있어야 한다.
- 증상명을 진단명으로 확대하지 않는다.
- 부분 부정·모호함·과거력을 현재 양성으로 바꾸지 않는다.
- 자유 텍스트 매핑 실패는 원문 전체를 SOAP에 넣지 않고 `미분류 임상 근거 [eID]`로 내부 감사에 남긴 뒤 필요할 때 한 번만 명료화한다.
- SOAP 렌더러는 필드별 예산을 두고 임상 중요도, 상충, 새 정보를 중복·배경 정보보다 우선한다.

## 단계별 검증

1. 구조화 fixture: 양성·부정·부분부정·과거·가족·수치·상충 응답의 개념·속성·출처를 검증한다.
2. SOAP-only A/B: 질문·진단·발화를 같게 유지하고 raw append와 개념 압축만 비교한다.
3. Question-only A/B: 기록을 고정하고 원본 질문 정책과 가치 점수 정책만 비교한다.
4. 결합 후보는 두 단일 변경이 각각 지지되었을 때만 만든다.
5. C01·C03·C10 모두 진단 일치, 비정상 종료 0, 안전·효율 회귀 없음을 확인한다. 공식 샘플에서 정보수집·의사소통 상승을 확인해야 채택한다.
