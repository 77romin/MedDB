# 주호소별 표준 문진·진찰 프로토콜 (E10)
#
# 왜: 커버리지(CareCoverage)의 주호소별 깊이가 공개 샘플 3개 주호소(불면·체중 감소·저신장)에만 있었다.
#     나머지 16개 주호소는 진찰 1~3개, 핵심 소견 몇 개뿐이라 비공개 증례에서 '빠진 필요 문진·진찰'이 반복됐다
#     (모의 증례 채점: 안저·뇌신경·소뇌, 경정맥, 비강·흉부 타진, 탈수 진찰, 청력, 낙상·독거, 임신, 유발 약물 등).
# 무엇: 외래 초진 표준(OSCE 체크리스트 수준)의 일반 임상 원칙만 담는다. 공개 샘플 대본·정답은 쓰지 않는다.
#
# 형식
#   #<주호소 id>            (default = KB 밖 주호소)
#   q: <id> | <질문> | <기록칸 hpi/pmh/fh/sh/ros> | <조건(선택)>   새 질문 (한 번에 한 가지만, 공백 포함 30자 이내)
#   f: <소견 id> | <조건(선택)>                                    기존 소견 질문을 이 주호소에서도 묻는다 (KB가 추적)
#   x: <진찰 id> | <조건(선택)>                                    진찰 (위에서부터 중요한 순서)
#   q:·f:도 위에서부터 묻는다 → 위험 신호, 흔하고 되돌릴 수 있는 원인(약물 등) 먼저 (E14: 질문 상한 32에서 꼬리가 잘림)
#   family: no                                                     급성 질환: 일반 가족력 질문을 하지 않는다
#   s: <문장>                                                       마무리 위험 신호 기본 문장 (모델 문장이 없을 때, 30자)
#   조건: sex=F, sex=M, age>=50, age<18, age=12-55 (공백으로 여러 개)
#
#   @exams 블록: 진찰 사전에 없는 진찰을 등록한다.  x: <id> | <진찰명> | <행동 문장>
